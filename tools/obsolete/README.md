# Obsolete araçlar

Bu klasördeki araçlar eski `assets/data/generated/` harita veri akışına aittir
ve aktif oyun tarafından çağrılmaz. Aktif senaryo verileri
`assets/scenarios/<senaryo_id>/data/` altında tutulur.

Araçlar tarihsel referans veya manuel veri kurtarma ihtiyacı için korunur;
çalıştırılmadan önce yollarının güncel senaryo yapısına uyarlanması gerekir.
